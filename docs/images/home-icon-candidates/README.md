## Oh My Zsh 官方标识参考

[官方彩色字标 PNG](oh-my-zsh-official-wordmark.png) 来源为 [官方仓库 README](https://github.com/ohmyzsh/ohmyzsh/blob/6010fb6260f359e71d99ba25f05f9215809b3ed2/README.md) 引用的 [原图](https://ohmyzsh.s3.amazonaws.com/omz-ansi-github.png)。它与 Devicon 的 SVG 是两个不同视觉版本，分别保留。首页使用 Devicon SVG；官方 PNG 仅作参考，不打包。已核对官方仓库与官网，尚未找到这个官方字标的 SVG 原文件。

## 其他统计项

Formula、Cask、更新、全局包数量与 nvm 默认版本使用微软 Fluent UI System Color Icons 的彩色功能 SVG；Command Line Tools 按用户选择使用本机 Apple 终端 App 的官方图标，见[功能图标素材](functional/README.md)。这些是用途示意图，不称为对应统计项的官方品牌 Logo。

[SHA256SUMS](SHA256SUMS) 记录下载 SVG、PNG 与许可原文的 SHA-256。
